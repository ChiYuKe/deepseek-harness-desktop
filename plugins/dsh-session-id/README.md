# DSH Session ID

这个插件提供类似 Codex 的命令式会话 ID 工作流，不增加顶部按钮或侧边栏入口。

## 使用方式

打开斜杠命令菜单，点击 `session-id`，会直接弹出最近的历史会话列表。点击目标会话后，插件会在当前会话中载入它的上下文，不会跳转页面，也不需要手动复制粘贴 ID。

如果想撤销，重新打开 `session-id`，点击列表第一项「取消当前继续」即可；同一会话不会叠加多个待处理引用。

如果列表里没有目标会话，仍然可以手动输入命令：

在当前会话直接发送：

```text
/session-id
```

命令结果就是当前会话 ID。

在新会话中输入旧会话 ID：

```text
/session-id <会话ID>
```

发送后不会跳转到旧会话，也不会改变当前会话 ID。插件会把旧会话的可见对话快照注入当前会话，随后你在当前会话发送的新消息就会以旧会话为背景继续处理。

命令执行完成后，当前会话会立即在输入框区域提示载入结果；不需要先发送一条普通消息才能确认命令已经生效。真正的跨会话上下文会在下一条普通消息发送时交给模型处理。

如果还没有发送下一条普通消息，可以在当前会话输入下面的命令取消载入：

```text
/session-id cancel
```

也支持 `/session-id 取消`。取消只会移除当前会话中尚未使用的跨会话上下文，不会影响旧会话。

旧会话保持不变。注入的是一次性的只读快照，不是实时同步；旧会话后续新增的消息不会自动出现在当前会话中。
